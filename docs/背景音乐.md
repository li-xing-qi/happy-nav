# 背景音乐：从「合成器循环」换成真实曲目

## 之前是什么、为什么单调

旧版 `public/audio.js` 用 WebAudio 现场合成背景音乐：固定 `C - Am - F - G` 四小节、
正弦波铺底、每小节三颗高音。不加载任何文件，好处是零带宽，坏处是——

- 和声永远一样，听两分钟就知道下一秒是什么；
- 只有一个音色，没有鼓、没有贝斯、没有留白；
- 情绪不可分场景，白天夜里一个味儿。

## 现在是什么

`public/music/` 下 12 首真实曲目（Mixkit 免费授权），按场景分四组轮播，
播放器在 `public/audio.js` 里，**不再走合成器**（合成器只在加载失败时兜底）。

| 场景 | 什么时候用 | 曲目 |
|---|---|---|
| `daily` | 白天默认（6:00–18:00） | Chillax / Walking in the Park / Feeling Good / Smooth Like Jazz / Piano Reflections |
| `love` | 傍晚夜里（18:00–23:00） | Old Letter / Love is Eternal / Piano Reflections / We'll Be Okay |
| `night` | 深夜（23:00–6:00） | Staring at the Night Sky / Rest Now / Lullaby Night / Vastness |
| `focus` | 下棋、牌局（页面可显式传） | Vastness / Piano Reflections / Rest Now / We'll Be Okay |

场景由 `startBgm()` 自动按当前钟点选；页面想指定就传参：`WNAV_AUDIO.startBgm('focus')`，
运行中临时换场景用 `WNAV_AUDIO.setScene('night')`。

## 播放器做了什么

- **洗牌轮播**：一场景内随机，但不会同一首连着放。
- **交叉淡化**：两个 `<audio>` 轮流上，2.2 秒淡入淡出，不硬切。
- **共用音量**：音频经 `createMediaElementSource` 接进原来的 `bgmBus → master`，
  所以全站的音量条、静音键、切后台暂停**全部照旧生效**，不用改任何页面。
- **兜底**：清单拿不到 / 连续三首加载失败（离线、文件丢了）→ 自动切回老的合成器，
  页面不会突然安静。`WNAV_AUDIO.state().source` 会告诉你是 `files` 还是 `synth`。
- **移动端**：沿用「首次点击才启动」的策略（`yu.html` 里那个 once 监听），
  绕开浏览器自动播放限制；切到后台暂停，切回来续播。

## 为什么音频文件不进仓库

12 首 25MB，进 git 会永久留在历史里。仓库只放：

- `public/music/manifest.json` —— 曲目清单 + 场景分组（前端唯一依赖）
- `scripts/fetch-music.sh` —— 按清单下载 + ffmpeg 转 112kbps（约 2MB/首）

```bash
bash scripts/fetch-music.sh          # 缺什么补什么
bash scripts/fetch-music.sh --force  # 全部重下
```

`public/music/*.mp3` 已写进 `.gitignore`。**换机器/新部署必须先跑一次这个脚本**，
否则页面会静默退回合成器（不报错，只是又变回单调那个版本）。

## 加歌 / 换歌

1. 在 Mixkit 上找到曲子，记下 URL 里的 id（`assets.mixkit.co/music/<id>/<id>.mp3`）；
2. 把 `id slug` 加进 `scripts/fetch-music.sh` 的 `TRACKS` 数组，跑脚本；
3. 在 `public/music/manifest.json` 的 `tracks` 里加一条，并把 id 塞进某个 `scenes` 数组。

漏了第 3 步不会报错——只是那首歌永远不会被播到。
