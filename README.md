# 和鱼的快乐导航

> 一个自带 AI 伙伴的网页导航站：聊天室、万象牌、五子棋、心有灵犀、与鱼。
> 零第三方依赖、纯 Node 内置模块、开箱即跑。

一句话说明它是什么：**你部署一个网站，站里有一个能聊天、有记忆的 AI 小伙伴，还有四个可以自己玩或联机的页面。**

---

## 先说清楚：哪些是自带的，哪些要你自己接

这个仓库是**站点本体**。它不包含作者私有环境里的另外几个进程（AI 陪玩代理、命令行助手桥接等）。所以：

| 能力 | 开箱可用？ | 说明 |
|---|---|---|
| 五个页面 + 双人对弈 + 联机房间 | ✅ 是 | 不配任何密钥就能玩 |
| 聊天室 AI 对话 | ⚠️ 要配模型 | 填 `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` 即可，任何 OpenAI 兼容接口都行 |
| 四层记忆（人设/近期/长期/偏好） | ⚠️ 要配模型 | 已内置在 `memory/`，作用于聊天室与游戏内 AI 助手 |
| 五子棋 AI 对手 | ❌ 否 | 站点本身是**双人对战**；AI 需要你自己接一个会调 `/api/go/move` 的客户端 |
| 万象牌 AI 队友 | ❌ 否 | 引擎与玩法完整（可双人合作），但 AI 队员同样需要外部接入 |
| 与鱼「跑命令 / 改文件 / 画图」 | ❌ 否 | 这里只有聊天房间 + 附件上传；「干活」依赖外部 agent 桥接 |
| 语音朗读 | ⚠️ 默认关闭 | 开启后走微软在线 TTS，朗读文本会离开本机 |

**一句话**：不配 AI 时，它是一个干净的双人聊天室 + 棋牌室；配了 AI，聊天室那边才活过来。上面标 ❌ 的三项，是这个仓库**没有**实现的能力，别抱期待。

## 三十秒跑起来

选一种就行。

### 方式一：Docker（最省事，推荐）

```bash
git clone https://github.com/li-xing-qi/happy-nav.git
cd happy-nav
docker compose up -d
```

打开 `http://localhost:3000` 即可。数据落在当前目录的 `data/` 与 `workspace/`，删容器不丢。

### 方式二：一条命令（Linux / macOS，有 Node 就行）

```bash
git clone https://github.com/li-xing-qi/happy-nav.git
cd happy-nav
bash deploy.sh
```

脚本会自动检查 Node 版本、建目录、生成配置、做语法自检，然后启动。后台跑用 `bash deploy.sh --daemon`，停止用 `bash deploy.sh --stop`。

### 方式三：Windows 双击

1. 装 [Node.js 18+](https://nodejs.org/)
2. 下载本仓库（`Code` → `Download ZIP`）并解压
3. 右键 `start.ps1` → 「使用 PowerShell 运行」

脚本会做和上面一样的检查与启动。

### 方式四：手动三步

```bash
npm start
# 或者
node server.js
```

**环境要求**：Node 18 或更高。不需要数据库、不需要构建、不需要 `npm install`（本项目零第三方依赖）。

## 部署完先做什么

1. 打开 `http://localhost:3000`，六个玩法都能点开
2. **想启用 AI 对话**：复制 `.env.example` 为 `.env`，填入你的模型服务地址与密钥（任何 OpenAI 兼容接口都行），重启服务
3. **想改 AI 的性格和称呼**：编辑 `workspace/AGENTS.md`，保存即生效
4. **想让它记住你**：直接编辑 `workspace/MEMORY.md`（一行一条）。长期记忆由后台任务自动沉淀，模型本身没有写入工具

> 没填 AI 密钥也能跑：站点、牌局、棋局都正常，只是没有 AI 陪聊与出招。

## AI 伙伴：四层记忆是怎么工作的

它不是一个「每次对话都从零开始」的聊天机器人。记忆分四层，越往下越久、越粗：

| 层 | 存什么 | 什么时候压缩 |
|---|---|---|
| **临时** | 这一局里每一步动作 | 满一定条数或一局结束时，提炼成摘要上浮 |
| **近期** | 最近几天的全部往来 | 渲染时按时间窗口与条数裁剪（只裁注入内容，文件不删） |
| **长期** | 浓缩后的事实，每条带时间 | 沉淀足够久才浓缩成长期；更久远的时效性内容低频归档 |
| **适配器** | 「怎么做事」的规矩与偏好 | 不按体积压缩，按作用域失效（单次 / 本局 / 长期） |

三条硬规则：

1. **人设与长期事实永不被裁剪**——预算是给人设和历史让路的，不是反过来。
2. **压缩不等于删除**——被浓缩、被归档的记录都还在文件里，可追溯。
3. **长期层改动频率远低于近期层**——不会把昨天的闲聊立刻变成长期事实。

细节见 [`docs/部署与维护手册.md`](docs/部署与维护手册.md) 第 1 章。

## 配置项

全部可选，不填就用默认值。完整清单见 `.env.example`，常用几个：

| 变量 | 默认 | 作用 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址；只想本机访问填 `127.0.0.1` |
| `DATA_DIR` | `./data` | 运行数据目录 |
| `WORKSPACE_DIR` | `./workspace` | 人设与记忆目录 |
| `LLM_BASE_URL` | 空 | 模型服务地址（OpenAI 兼容） |
| `LLM_API_KEY` | 空 | 密钥；留空则不启用 AI 对话 |
| `LLM_MODEL` | 空 | 模型名 |
| `TTS_ENABLE` | `1` | 设为 `0` 关闭语音 |
| `FOUR_LAYER` | `1` | 设为 `0` 关闭四层记忆增强 |

## 改代码前须知

这个项目有几个历史遗留的坑，改之前请务必读 [`docs/部署与维护手册.md`](docs/部署与维护手册.md) 的第 2 章（结构与调用约束）、第 9 章（自检与事故清单）、第 10 章（改造风险）。

其中最容易踩的三条：

1. **`server.js` 顶层直接 `listen`，不要 `require` 它** —— 会在同进程里再启一个服务器、端口冲突。需要复用的只有 `engine.js`（纯逻辑库）。
2. **`server.js` 里有 8 个 `[EXTERNAL-DEP · PATCH n/8]` 标记块** —— 整文件重写会导致补丁丢失。改完用 `grep -c "PATCH .*/8" server.js` 检查是否还是 8。
3. **前端内联脚本要单独检查** —— `node --check` 不管 HTML 里的 `<script>`，改动后请真点一遍页面。

## 安全与隐私

**先说风险，别等出事**：这个项目的房间号只是「知道就能进」，**不是身份认证**。放在公网上任何人都能进来聊天、上传文件、调用 AI 接口（花你的额度）。它最初是局域网自用设计的，不是为公网准备的。

- **破坏性接口已加保护**：清理上传文件这类接口默认只允许**本机回环地址**调用。需要远程调用时，在 `.env` 里设 `AUTH_TOKEN`，请求带上 `x-auth-token` 头或 `?token=`。
- **`/api/chat` 是公开的模型代理**：谁能访问页面谁就能让它说话、消耗你的额度。**公网部署前务必加一层访问控制**（反向代理 + Basic Auth 最省事）。
- **`/api/health` 不再回显模型地址**，只告诉你「有没有配密钥」。
- **站点数据都在你自己的机器上**：聊天记录、上传文件、记忆都写在本地目录，站点本身不上传任何第三方。
  **例外**：① 聊天内容会发给你配置的模型服务（那是你自己的选择）；② 语音合成默认关闭，开启后文本会发往微软在线服务。
- **`.env`、`data/`、`workspace/` 已被 `.gitignore` 排除**，不会被误提交。
- AI 密钥只从环境变量读取，不写在代码里。

**想放公网？至少做这三件事**：反向代理加账号密码、`AUTH_TOKEN` 设一个随机串、限制 `/api/chat` 的调用频率（这一项本项目没做，需要你在代理层加）。

## 常见问题

**Q：没配 AI 密钥能用吗？**
能。站点、牌局、棋局、心有灵犀都正常，只是没有 AI 陪聊与出招。

**Q：端口被占用怎么办？**
`PORT=3001 bash deploy.sh`，或改 `.env` 里的 `PORT`。

**Q：手机能访问吗？**
能，把地址里的 `127.0.0.1` 换成本机内网 IP。要公网访问需要自己做端口映射或反向代理。

**Q：数据在哪？怎么备份？**
`data/` 与 `workspace/` 两个目录，直接复制走就是完整备份。恢复时放回原位即可。

**Q：语音念不出来？**
需要 Python 与 `edge-tts`：`pip3 install edge-tts`；不需要就把 `TTS_ENABLE=0`。

**Q：AI 记不住我说的话？**
先确认 `.env` 里 AI 配置正确，再看 `workspace/MEMORY.md` 是否有内容。长期记忆是异步沉淀的，不会立刻写入。
