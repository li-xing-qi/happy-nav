33KB 的安卓壳：把你的站点装进一个干净的 WebView，没有开屏广告、没有推荐流、没有第三方统计。

**它不提供服务器，也不带模型 key。** 页面、AI、记忆都在你自己那台机器上，这个 App 只是连过去。

## 装

1. 下载下面的 `happy-nav-1.4.1.apk`
2. 手机上点开安装（第一次要允许「未知来源」）
3. 首次启动填你自己的地址，例如 `http://192.168.1.10:3000`；地址只存在本机

从 1.1 / 1.3 / 1.4 升级可以直接覆盖安装——签名没换，聊天记录和地址都保留。

## 这一版（1.4.1）最重要的两件事

### 1. 退出应用也能收到她的消息

以前 App 一退到后台，WebView 被系统挂起，那条实时连接就断了，所以她说什么你都不知道。
1.4 起多了一个**前台服务**，界面关掉以后它继续守着房间，她说话就弹通知：

- 常驻一条静默通知「与鱼 · 守着消息，先别关我」——前台服务必须挂，关掉系统就会收走服务
- 她说话时是**高优先级通知**：横幅 + 响铃 + 震动，点一下直接回到与鱼页
- 自己发的不弹；你正看着屏幕时也不弹
- 从最近任务里划掉不会断（`stopWithTask=false`）

**第一次进与鱼页会问通知权限**（Android 13+ 必须给），不在启动时打断你。

### 2. 能发语音了（http 地址也行）

页面录音用的是 `getUserMedia`，而浏览器只在 https / localhost 下给麦克风。
用 easytier 的内网地址是 `http://`，WebView 里 `navigator.mediaDevices` **直接是 undefined**，
点「开始录音」只会得到一句「这个环境不给录音」——这个在 WebView 里没有开关能绕。

1.4 起来录音改由原生 `MediaRecorder` 做：点「开始录音」→ 第一次要给麦克风权限 →
说完点 **「■ 停止并发送」**。录完由原生自己上传，音频不经过网页。

顺手修了个原来的死锁：以前开始录音后「发送语音」按钮是禁用的，而解除禁用要等录音自己停，
录音又只能靠那个按钮停——所以录上以后根本没法结束。

## 其他

- 与鱼页头从 5 个图标减到 3 个（☰ ← ⚙）；音乐和「改地址/刷新/清缓存」搬到首页设置
- 连不上时给「重新连接」页，页面上有「地址填错了？改地址」
- 长按返回键也能唤出改地址（页面白屏时的最后一条出路）
- 发图 / 传文件 / 下载 / 外链交给系统浏览器，都照旧

## 限制（不吹牛）

- **没有厂商推送**。切后台、锁屏、从最近任务划掉都能收；**强行停止 App 收不到**。
  国产 ROM 建议把 App 加进电池优化白名单（设置 → 应用 → 电池 → 无限制），否则深度清理会杀服务。
- 通知栏**不能直接回复**（`RemoteInput` 还没做），点开进 App 回。
- **她听懂你说的语音**这件事在服务端做（本地 whisper 转写），不依赖这个 APK；
  APK 只负责把声音录下来传上去。
- 录音时切走会继续录（MediaRecorder 不跟界面生命周期）；不想发就点遮罩取消。
- `http://` 是明文传输，公共 WiFi 下能被抓包（要么上 https，要么走内网/隧道）。

## 源码与构建

`clients/android/`。不需要 Android Studio 或 Gradle：

```bash
bash build-apk.sh   # JDK 17 + build-tools + android.jar，六步出包
```

这一版同样**没在真机上跑过**（构建机没有设备/模拟器）。已验证：能编译、
签名校验通过、包名/版本/权限/启动 Activity 正确、dex 里 `NotifyService` /
`voiceStart` / `voiceSend` 都在。装完请重点试三件事：**收通知**、**发语音**、**发图**。
